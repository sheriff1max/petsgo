# Описание проекта

Представь, что у тебя 5 внешних магазинов, каждый «отвечает» со своей задержкой и своей ценой на один товар. Напиши cheapest(prices []int, delays []time.Duration) (price int, idx int): запусти по горутине на каждый магазин, каждая через свою задержку шлёт в канал пару (цена, индекс); main принимает ровно len(prices) ответов и выбирает минимум (при равенстве — меньший индекс). Общее время работы ≈ max(delays), а не сумма — в этом и смысл параллельности.
