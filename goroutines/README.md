# Мини проекты с горутинами

Технологии: Go (`sync`), горутины, WaitGroup, каналы, мьютиксы.

Детали ТЗ каждого из 9 мини проектов можно прочесть в `readme.md`.

При работе с горутинами отработал навыки параллельных вычислений, передача данных между горутинами с помощью каналов, ожидание окончания всех горутин, блокировка горутины при работе с общим ресурсом.
