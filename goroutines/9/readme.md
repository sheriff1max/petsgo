# Описание проекта

Задача из жизни: нужно обработать N задач, но не больше K одновременно (чтобы не уронить базу/API). Напиши process(n, k int) []int: буферизованный канал ёмкостью k работает как семафор — перед стартом горутина кладёт туда заглушку, в конце (через defer) вынимает. Каждая задача «спит» 5 мс и возвращает свой номер. Собери результаты в срез (запись в разные индексы безопасна) и дождись всех через WaitGroup. Убедись, что общее время ≈ ⌈n/k⌉ · 5 мс, а не n · 5 мс.
Тренирует: буферизованный канал как семафор, defer для освобождения, WaitGroup, безопасная запись в разные ячейки среза.
