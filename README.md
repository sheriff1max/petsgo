# Проекты на Go

## MiniSocial

О проекте: REST-сервис минималистичной социальной сети с лентой новостей, подписками и лайками.

Стек: Go (Chi, pgx), PostgreSQL, Docker Compose, Swagger.

Что сделано: структура проекта, SQL-миграции, Makefile для автоматизации сборки и генерации документации, полностью контейнеризированный API с автодокументацией и готовой инфраструктурой для развертывания.
