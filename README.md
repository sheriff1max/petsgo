# Проекты на Go

## <a href='/minisocial/'>minisocial</a>

О проекте: REST-сервис минималистичной социальной сети с лентой новостей, подписками и лайками.

Стек: Go (Chi, pgx), PostgreSQL, Docker Compose, Swagger.

Что сделано: структура проекта, SQL-миграции, Makefile для автоматизации сборки и генерации документации, полностью контейнеризированный API с автодокументацией и готовой инфраструктурой для развертывания.

## <a href='/databases/'>databases</a>

О проекте: работа с разными СУБД.

Стек: Go, PostgreSQL, MySQL, SQLite, MongoDB, Docker Compose.

Что сделано: небольшие приложения для взаимодействия с различными базами данных. Отдельный мини проект реализует миграцию из одной БД в другую.

## <a href='net-http'>net-http</a>

О проекте: приложения с реализациями базовых серверов и клиентов на Go.

Стек: Go (`net`, `net/http`).

Что сделано: небольшие приложения с TCP и HTTP подключениями между сервером и клиентов.

## <a href='goroutines'>goroutines</a>

О проекте: работа с горутинами.

Стек: Go (`sync`), горутины, WaitGroup, каналы, мьютиксы.

Что сделано: небольшие приложения для ускорения вычислений с помощью горутин.
