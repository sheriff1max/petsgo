# Описание реализации

Сервер команд: читает с соединения строки через bufio.Scanner в цикле (сессия: несколько команд на одно соединение). ADD a b → ответить суммой, ECHO <текст> → вернуть текст, всё остальное → ERR. Клиентская функция-помощник ask(addr, line string) string (dial → запись → чтение одной строки → close) и askTwo(addr, l1, l2) (string, string) — две команды в одной сессии.
