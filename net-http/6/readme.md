# Описание реализации

HTTP-сервер с состоянием: POST /set сохраняет присланное тело как текущую цитату (хранение под sync.Mutex), GET /get возвращает её. Клиентские обёртки setQuote(addr, text string) error (через http.Post) и getQuote(addr string) string. Проверь последовательную перезапись цитаты — состояние должно жить между запросами.
