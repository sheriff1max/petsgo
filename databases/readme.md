# Мини проекты на разных СУБД

В проекте использовались:
- SQLite
- PostgreSQL
- MySQL
- MongoDB

Технологии: Go, Docker-Compose.

Детали ТЗ каждого из 5 мини проектов можно прочесть в `readme.md`.

В каждом проекте отрабатывались различные тонкости работы с каждой из СУБД.

Кроме того, был реализован мини проект миграции от SQLite в MySQL.

## Возможные ошибки

Если программа не подключается к БД, то вероятно порт занят. Например, для PostgreSQL нужно бновить docker-compose.yml, извенив секцию **ports** с `"5432:5432"` на `"5433:5432"` (слева порт хоста, справа порт внутри контейнера).
